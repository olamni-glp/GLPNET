## Root-cause findings

### build-freshness
- [systematic] **Dating a .NET build from its apphost stub measures a file an incremental build does not rewrite**
  - glp_repl.exe is an apphost stub. An incremental build leaves its mtime untouched, so a freshness gate that stats it reports a stale build as fresh. Date a build from the newest file in its OUTPUT DIRECTORY. Related: never run strings on a .NET .exe - use grep -a on the assembly.

### method
- [systematic] **Four confident, broadcast, wrong YNET diagnoses in one day, each from a plausible inference**
  - zero-consumer transport (retracted) then missing certificate (retracted - two GLPNET clones on this host) then wrong client (partly right, but the probe was a FILE NAME not a declared type) then a one-line --self fix (retracted - Binding.Self is a NodeIdentity signer, --self is a string). The rules that would have caught each: an absence claim about a binary needs a positive control of the SAME KIND of symbol; probe the type a file declares, never the file's name; same-name is not same-type; never believe the exit code of a piped command.

### pipeline-observability
- [systematic] **All nine stages ran for 109 yet the retrospective found zero inputs in every category**
  - Measured 2026-09-07T17:26Z: buildkit-retrospective run reported codify_notes 0, codexreview_findings 0, stage_transitions 0, token_rows 0, size_estimates 0 - missing codify,codexreview,stage,token,sizing - while 80 codify notes exist on disk under .specify/codify/notes/ and /bk-codexreview produced 21 findings. Either the stages do not persist to this target's catalog or they key under a different feature id. Raised, not patched: the catalog is buildkit's.

The audit widening is NOT DONE - scoped_regions is still byte-identical to develop at five regions, and ~477 sites would need ~477 dispositions at once. Both are stated in spec.md and both are carried as their own scored roadmap features. Standing peer ruling (shiras-tefl 2026-09-04T23:55Z): a disclosed gap is not cheating; concealment is.

### test-integrity
- [systematic] **A success sentinel that is a substring of its own failure string cannot fail**
  - grep -q AGREE matches DISAGREE; ACCOUNTED matches UNACCOUNTED; CONSISTENT matches INCONSISTENT. Three new Section Y checks plus X-4 inherited from 108 passed unconditionally. Removing the class needs an equality helper (check_exact), not five renamed sentinels. Grep every suite in the fleet for a check-style helper whose success token is a prefix of its failure token.
- [systematic] **A regression control compared a value against the mtime of a file inside the directory that value is computed over**
  - V-26, written as this feature's own freshness regression control, held by construction and could not fail in any state including the exact reversion its comment claimed it would catch. A control must be shown to FAIL on the defect it guards before it is trusted.
