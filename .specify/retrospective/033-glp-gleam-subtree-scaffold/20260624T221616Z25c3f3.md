- [systematic] **Spec-literal wording overrides silencing a compiler warning**
  - Placeholders used 'pub const subsystem' to silence Gleam's empty-module warning, but tasks T009-T016/R-006 literally say 'no exported definitions'. Codexreview (both reviewers) flagged it; fix = doc-only. Warnings are not errors; the literal spec governs. R-006's pub-const fallback was conditioned on doc-only FAILING to build, which it did not.
- [systematic] **Pin shell scripts to LF via .gitattributes for WSL gates under core.autocrlf=true**
  - This repo has core.autocrlf=true; a CRLF smoke.sh dies under WSL bash ('set: pipefail: invalid option name', exit 2) — verified empirically. glp_gleam/.gitattributes '*.sh text eol=lf' makes the WSL gate survive a Windows checkout. Reusable for any future cross-OS shell gate here.
- [one_off] **Verify with commit-range diffs, not working-tree diffs, when WSL-git and Windows-git share a tree**
  - WSL-git (no autocrlf) perceives the Windows working tree's CRLF files as differing from LF blobs, producing false-positive 'changed' lists (e.g. 60 codeconv files in quickstart step 6). The contract's authoritative SC-006 check uses git diff merge-base..HEAD (line-ending-immune) and was empty. Use commit-range diffs for verification.
