### adversarial-bounds
- [systematic] **Bounded-behavior spec promises lacked enforcement and adversarial tests**
  - Spec edge case promised bounded, deterministic behavior for very large schema documents, but counted-repeat NFA expansion was unbounded (OOM/SOE from a short pattern) and three recursive walks (acyclicity DFS, type-ref nesting, pattern group nesting) had no depth guards. Tests never exercised adversarial sizes until the review added blowup/50k-chain regressions. Prevention: every bounded-behavior promise in a spec gets a hard cap constant + a loud named error + an adversarial regression test in the same task that implements the feature.

### loud-fail-gates
- [systematic] **Precondition-trusting public overloads produced raw exceptions or unbounded behavior**
  - Public entry points that trusted caller-validated documents (explicit-document InstanceValidator overload, RegisterVersion/CheckVersion/Register document paths) let unvalidated input reach deep code: raw KeyNotFoundException, silent pattern-skip, registry invariant misattribution, cyclic-schema stack overflow. Fixed with named-error gates (SchemaErrorsOf, cycle check, Resolve/NfaOf conventions). Prevention: FR-014 loud-fail review of every public API surface, not just the happy-path pipeline.

### representation-boundaries
- [systematic] **Representation-boundary defects cluster: independently-defined alphabets/escape models across the DSL and CDDL-subset surfaces**
  - Nine of 25 confirmed review defects sat on textual-surface boundaries: occurs scalar/list shift, printer/lexer bareword alphabets, long-to-int casts, string-blind bracket scanning, trailing-backslash escape model, non-DSL element/rule names in lift. Root cause: the DSL grammar and the CDDL emitter/parser evolved with separately-implied alphabets and escape conventions; no single normative alphabet+escape section existed until review amendments to schema-dsl.md. Prevention: define shared alphabet/escape laws in the contract FIRST and generate/enforce both surfaces from them.
