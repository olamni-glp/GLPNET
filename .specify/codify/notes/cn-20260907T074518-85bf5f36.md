MEASURED SHIRAS 2026-09-07. The engineer's three-tier coordinator mandate (fleet leader + per-host coordinator + per-lane sub-coordinator, QHSM/QMSM C# actors, 2-min nonced liveness over kernel mailboxes, never file-based) is ALREADY BUILT in yngenios L0 and hosted by NOTHING: CoordinatorTier{Fleet,Host,Lane}, CoordinatorId with derivable Mailbox, LivenessTransport{FileDropbox,KernelRealtime}, CoordinatorMachine (the QHSM actor), LivenessWatch, WatchRound, WatchVerdictKind - all referenced only by tests/L0.Tests/Coordinator/*, zero production consumers, across 210 C# files and 333 declarations. This is W-06 repeating on F-1, the fleet's most-cited automatic-failure condition: the fleet sat leaderless for a day while the logic that would have caught it sat in L0, green, called by nothing. THREE COMPOUNDING ROOT CAUSES, each measured: (1) NO CONSUMER - capability declared, documented, unit-tested, never wired to a host process; (2) NO DISCOVERY - lanes cannot find what already exists, so in one hour four lanes independently proposed or built duplicates of already-built capability (node-identity, coordinator hierarchy, liveness ping) and then withdrew; (3) FALSE GREEN - a guard returning not_applicable renders identically to a guard that passed, so every non-buildkit repo on four hosts was unguarded against this class while appearing green. THE INSTRUMENT LESSON, learned three times in one session by pointing tools at my own work: my alert census was CWD-RELATIVE and reported a false clean from any other directory; my consumer census was SINGLE-LANGUAGE and missed a live Python implementation answering pings in 5ms; my guard's headline UNVERIFIABLE verdict was never actually exercised because the test directory happened to contain files of the scanned language. RUN YOUR INSTRUMENT AGAINST YOURSELF FIRST. WHAT MUST HARDEN INTO GA: a cross-language declared-but-unconsumed gate where UNVERIFIABLE is a first-class verdict that can never be folded into a pass; a fleetwide host-by-host lane-by-lane deployment workflow that is tracked, verified and durably evidenced per lane; and a CRDT Feature Requirements document that all lanes converge on conflict-free rather than forking under one filename as OB-8 did four ways.
