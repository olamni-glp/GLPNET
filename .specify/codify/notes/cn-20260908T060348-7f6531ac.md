CONCRETE EVIDENCE FOR THE TOP UNBUILT BOARD ROW, found by running the two planes side by side rather than by reading them. Measured 2026-09-08T06:02Z on OLAMNIT: the FILE plane writes Origin as a NAME (olamnit/olamnit.glpnet, per CoopFileCarrier BuildFrame which sets Origin/SenderNode/SenderActor from PeerIdentity), while the WIRE plane writes Origin as the sender's NODE ID (1d7d7ded...8c0c). Same field, same contract, two incompatible value spaces. Any consumer that groups, filters or de-duplicates by Origin will treat one lane as two distinct senders the moment a frame arrives over the other plane - and will do so SILENTLY, because both values are non-empty well-formed strings. This is exactly ynet-frame-field-parity-across-planes (WSJF 10.50, RICE 80750). The parity fix must decide which space Origin lives in AND carry the other as a distinct field; collapsing them loses either human addressability or cryptographic attribution.
