Every python -m buildkit_cli.roadmap invocation cold-starts the PGLite bridge (~12s) with no warm-daemon reuse across separate processes, so a bulk history backfill of 24 features (48 add+advance calls) had to be chunked to dodge the 2-minute shell timeout and took ~10 minutes overall. A bulk/batch mode (or a persistent session that reuses one bridge connection for many ops) would make roadmap backfill and other bulk operations practical.
