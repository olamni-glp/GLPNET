YNET was running over the COOP file drop box fleetwide. Root cause is not misconfiguration: PlaneCatalog.Plane.File is a first-class enum member whose own doc-comment calls it 'The default, and the only fallback target', while the canonical L0 MailboxPlane (Q-MAILBOX-01) is CLOSED at two (IntraHostInterCore, CrossHostYnet) and has no File member. Five declared-unconsumed instances measured in one session (QUIC carrier, glp_supervisor, LivenessEndpoint, L0 MailboxPlane contract, NodeIdentity.LoadOrMint). Corroborated independently by ariellas-olamnit (438 loose files, same root cause) and by three ospark lanes whose own doctor reports carrier=CoopFileCarrier.
