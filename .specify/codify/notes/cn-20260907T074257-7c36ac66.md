YNET ran over the COOP file drop box fleetwide. Root cause is NOT misconfiguration: PlaneCatalog.Plane.File is a first-class enum member whose own doc-comment calls it 'The default, and the only fallback target', while the canonical L0 MailboxPlane (Q-MAILBOX-01) is CLOSED at two (IntraHostInterCore, CrossHostYnet) and has no File member. Two enums model one concept and the client binds the one admitting the prohibited plane. FIVE declared-unconsumed instances measured in one session: QUIC carrier, glp_supervisor, LivenessEndpoint, the L0 MailboxPlane contract, and NodeIdentity.LoadOrMint (389 lines, hardened by 3 commits, zero production consumers). Corroborated independently by ariellas-olamnit (438 loose files, same root cause) and three ospark lanes whose own doctor reports carrier=CoopFileCarrier. Also: a scored roadmap row carrying a stale Measured date is more dangerous than an unscored one - three lanes cited ynet-node-identity-persistence as the blocker and it had already shipped.
