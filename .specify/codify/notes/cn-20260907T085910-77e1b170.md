A mandatory era was assigned on the premise that the QUIC listener was unbuilt work sitting on a promoted roadmap row. Measured before starting: the listener exists (228 lines), is CONSUMED by QuicCarrier.cs:105, binds a real QUIC listener on this host (msquic resolved by the .NET runtime), and node identity persists with a positive control - two glp_quic_probe runs moved origin Minted to Loaded with an identical nodeId and SPKI pin. The era is an INTEGRATION plus two named gaps (iroh tier-0 sidecar, 2-minute round-trip probe), not a build. The general lesson: a roadmap row being unstarted does not mean the CODE is unwritten - earlier eras had built it - and scoping an era from the row rather than from the tree would have duplicated working code. Also: relaying a true finding from another host into an unmeasured scope turns a correct measurement into a wrong conclusion; I did that with the two-halves-on-different-hosts finding and withdrew it.
