reconcile is structurally broken for every numbered spec dir: store.reconcile() matches the roadmap's unprefixed feature_id (e.g. semantic-tombstone-enrichment) against buildkit.pipeline_stage.feature_id which keeps the NNN- ordinal prefix (035-semantic-tombstone-enrichment), so it silently no-ops and can never advance a feature into planned/tasked/analyzed/implemented. speclink/link strips the prefix; reconcile does not.
