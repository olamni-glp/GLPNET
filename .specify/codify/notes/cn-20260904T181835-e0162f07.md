MEASURED by controlled experiment on SHIRAS 2026-09-04: Olamnit.Kernel.Tests passes 402/403 run alone and FAILS run concurrently with one other suite. Same commit, same host; the only variable was CPU contention. ROOT CAUSE: SloGate.IsReferenceHost is an OPT-OUT env flag (OLA_SLO_NONREFERENCE), so a host is reference BY DEFAULT and never checks - an 8-core box running 15 agent lanes enforced a 50k/s reference floor while delivering 24k/s then 35k/s. Its best-of-two retry cannot help because contention spans BOTH attempts. The gate asserted a property of the HOST while claiming to assert a property of the FABRIC. FIX: HostIsContended() measures descheduling with two independent signals (dispersion of a fixed CPU workload; Linux load-per-core) and a missed floor routes through one FailOrSkip decision - contended means a recorded INCONCLUSIVE carrying both numbers, quiet means Assert.Fail as a regression. Never a silent pass; consulted only AFTER a floor is missed so a quiet-host regression still fails. Fixing it surfaced a coverage hole: two SLO assertions bypassed the shared gate inline and one became the NEXT failure immediately. VERIFIED both directions: concurrent 400/403 0 failed (was 1 FAILED), quiet 401/403 with 5 of 6 gates enforced and passed. GENERAL LESSON, the third instance in one day: a DECLARATION standing in for a MEASUREMENT (reference-host flag; LD_LIBRARY_PATH greening tests while services stay deaf; a probe measuring the wrong configuration). Prefer a measured predicate over a declared one, and make the unsupported case LOUDLY INCONCLUSIVE rather than pass or fail.
