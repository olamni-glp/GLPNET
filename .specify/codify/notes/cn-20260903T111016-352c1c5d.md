Cross-lane host-contention round (2026-09-03, ARIELLAS, 13 live peer lanes) produced a genuinely better result than any single lane could, and the mechanism is reusable. WHAT WORKED: lanes independently measured the same host, then MECHANICALLY exchanged claims with mandatory evidence, and the disagreements - not the agreements - carried the value. Five findings only survived because a peer refuted a method. (1) METHOD BEAT EVIDENCE. Four lanes including glpnet cited a real command and still got the wrong CPU answer, because Get-Process reports 0.00 CPU for PROTECTED processes and hid Defender entirely. CIM Win32_Process KernelModeTime+UserModeTime deltas showed MsMpEng at 37.57pct of host - larger than all 14 agents combined. This is why qhstate-af's `method` field was added to the envelope: evidence-as-a-command proved INSUFFICIENT. (2) A NULL RESULT KILLED THE FAVOURED FIX. glpnet measured per-lane commit as an 881MB FLOOR (n=14, sd 55; a 14-hour session-age gap moves it 3.4pct), independently reproduced by tefl (883.1), crucible (868/872) and buildkit (847). Four samplers, four methods, same answer: the heap is model+tooling baseline, NOT accumulated context, so `--autocompact 1000000` is not the memory multiplier. That deleted the round's rank-1 lever and left lane count as the only one with magnitude. (3) SELF-REFUTATION WAS THE HIGHEST-VALUE CONTRIBUTION. glpnet filed FIVE retractions: the Get-Process method; "l0/ynet is one file" (the real YNET is 20 C# files + 11 test files); reusing the QActive mailbox for the work queue (in-memory, non-durable - would have lost queued work); ".pgdb.bridge.lock strands" (proper-lockfile stale:1000, contract says absent-of-lock IS authoritative - the bridge is crash-safe by construction, and a peer had already cited the wrong claim); and a format contradiction where the superset specified BOTH quarantine AND LWW-per-field, which are mutually exclusive - copied by every lane from the convening message. (4) THE FORMAT CONVERGED BY SUBSETTING, NOT VOTING. Final envelope is a strict superset: dot{peer,counter}+tombstone from glpnet's shipped glp_crdtmsg, lamport+supersedes from glpnet, confidence+op-vocabulary from peers, method+window+supersedes_reason from qhstate, origin_root from buildkit - each field justified by a failure OBSERVED IN THE ROUND, never by taste. WHAT TO REUSE: mandatory evidence + method + sampling window on every claim; supersedes_reason enum so an honest self-correction is distinguishable from being wrong (otherwise retracting is punished); quarantine-never-pick with corrections via tombstone edge, never field-level merge; and one ruled host-local root on the NVMe - the round forked into FOUR merge roots and had to be re-converged, which is the exact failure it was diagnosing.
