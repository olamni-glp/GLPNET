# Contract — Dependency Lock & Pinning

Acceptance surface for FR-005, FR-010, SC-004. Mirrors the F1-proven lock
(`docs/research/gleam-atomvm/hello-glp-term/manifest.toml`).

## `gleam.toml` dependency declarations

```toml
[dependencies]
gleam_stdlib = ">= 0.34.0 and < 2.0.0"
gleam_erlang = ">= 0.34.0 and < 2.0.0"

[dev-dependencies]
gleeunit = ">= 1.0.0 and < 2.0.0"
```
- **MUST list** `gleam_stdlib`, `gleam_erlang` (runtime) and `gleeunit` (dev).
- **MUST NOT list** `gleam_otp`. *(FR-005)*

## `manifest.toml` (committed lock) — required pins

| Package | Locked version | Scope |
|---------|---------------|-------|
| `gleam_stdlib` | **1.0.3** | runtime |
| `gleam_erlang` | **1.3.0** | runtime |
| `gleeunit` | **1.11.0** | dev |
| `gleam_otp` | **absent (0 occurrences)** | — |

- The manifest is **generated by `gleam` under WSL** (`gleam deps download` / `gleam build`) and
  then **committed** (its header: "You should check this file into your source control
  repository"). Never hand-edited. *(FR-005, R-002)*
- Build artifacts are **not** committed (`.gitignore`); the manifest **is**. *(FR-010)*

## Invariants

1. `grep -c gleam_otp glp_gleam/manifest.toml` == `0` and `grep -c gleam_otp glp_gleam/gleam.toml`
   == `0`. *(SC-004)*
2. The three locked versions equal the F1-ratified versions exactly. *(FR-005)*
3. `manifest.toml` is tracked by git; `build/` is not. *(FR-010)*

## Rationale (why omission, not exclusion syntax)

`gleam_otp` is kept out simply by **not declaring it**; F1's resolved manifest confirms none of the
three declared deps requires it transitively (each `requirements` list contains only
`gleam_stdlib`). There is no allow/deny mechanism to configure — absence in the committed lock is
the guarantee, and it is grep-verifiable. *(research.md R-002)*
