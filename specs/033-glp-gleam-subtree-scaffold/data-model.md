# Phase 1 Data Model — glp_gleam subtree scaffold

This feature has **no runtime data model** (no database, no schema, no migration). The "entities"
here are the **build-configuration and source artifacts** the scaffold produces, plus their
validation rules and relationships. They map directly to the Key Entities in `spec.md`.

## Entities

### E1 — `glp_gleam` subtree (the project root)
- **Description**: the new repo-root Gleam project directory; the buildable home + green baseline
  for the downstream port.
- **Location**: `glp_gleam/` at the repository root, sibling to `glp_runtime/`, `glp_runtime_net/`,
  `out/`, `codeconv/`.
- **Validation**:
  - MUST be a sibling of `glp_runtime/` and `glp_runtime_net/` (FR-001, US2 AS-3).
  - MUST NOT pre-exist (verified absent: no `glp_gleam/` today) — creation is additive (FR-009).
  - Contains exactly the children in E2–E8.

### E2 — Project metadata (`gleam.toml`)
- **Fields**: `name = "glp_gleam"`; `version`; `description`; `licences`; `[dependencies]`
  (`gleam_stdlib`, `gleam_erlang`); `[dev-dependencies]` (`gleeunit`).
- **Validation**:
  - `name` MUST match `^[a-z][a-z0-9_]*$`, non-reserved (FR-006) → `glp_gleam` ✓.
  - `[dependencies]` MUST list `gleam_stdlib` and `gleam_erlang` and MUST NOT list `gleam_otp`
    (FR-005, SC-004).
  - Ranges as proven by F1 (R-002).

### E3 — Committed dependency lock (`manifest.toml`)
- **Description**: the Gleam-managed lockfile, **committed** (FR-005/FR-010).
- **Fields**: `packages` (each with exact `version` + `outer_checksum`); `[requirements]`.
- **Validation**:
  - MUST lock `gleam_stdlib` **1.0.3**, `gleam_erlang` **1.3.0**, `gleeunit` **1.11.0** (SC-004).
  - MUST contain **0 occurrences** of `gleam_otp` (SC-004; grep-verifiable).
  - Generated by `gleam` under WSL, then committed — never hand-edited (R-002).
  - MUST be tracked by git (not ignored).

### E4 — Subsystem placeholder modules (×8)
- **Description**: one empty-but-building Gleam module per authoritative Dart subsystem.
- **Members** (1:1 with `glp_runtime/lib/`, verified): `analysis`, `bytecode`, `compiler`,
  `engine`, `link`, `lint`, `multiagent`, `runtime`.
- **Location**: `src/glp/<subsystem>.gleam` → Gleam module path `glp/<subsystem>`.
- **Validation**:
  - Exactly 8 modules; the set EQUALS the 8 subsystems (FR-004, SC-003) — no more, no fewer.
  - Each path segment legal + non-reserved (FR-006). (`lint`, `link`, etc. all legal.)
  - Each MUST compile as part of the build (SC-003), even if nothing imports it (edge case).
  - Empty-but-building, not empty-and-dangling: a `////` module-doc naming the subsystem + its Dart
    source path; no ported semantics (R-006).

### E5 — Smoke test (`test/glp_gleam_test.gleam`)
- **Description**: minimal gleeunit test proving the build-and-run path.
- **Validation**:
  - MUST yield ≥1 test, 0 failures under `gleam test --target erlang` (FR-003, SC-002).
  - Uses `gleeunit` (dev-dependency).

### E6 — Smoke script (`glp_gleam/smoke.sh`)
- **Description**: the local WSL-runnable build-and-test gate (FR-007).
- **Behavior** (see `contracts/build-test-smoke.md`):
  - Loud toolchain check (gleam 1.17.0; OTP 25) → actionable failure if absent/wrong (edge case).
  - `gleam build --target erlang` then `gleam test --target erlang`.
  - Exit 0 iff both green; non-zero otherwise (SC-005).
- **Validation**: executable; runnable under WSL from the subtree root; references only the pinned
  toolchain + the Erlang/BEAM target (not JS/AtomVM).

### E7 — Ignore rules (`glp_gleam/.gitignore`)
- **Description**: keeps build/output artifacts out of git (FR-010).
- **Content**: at least `*.beam`, `*.ez`, `/build`, `erl_crash.dump` (F1-proven set).
- **Validation**: `manifest.toml`, `gleam.toml`, `src/**`, `test/**`, `smoke.sh`, `README.md`
  remain **tracked**; `build/` and compiled artifacts remain **untracked**.

### E8 — Subtree README (`glp_gleam/README.md`) *(supporting, not spec-mandated)*
- **Description**: one screen — purpose (the F3 skeleton; where F4+ land), the build/test commands
  (SC-001/SC-002), the smoke gate, and a pointer to `docs/research/gleam-atomvm/dossier.md` §6.
- **Validation**: references, does not duplicate, the dossier (Principle VIII).

## Relationships

```
glp_gleam (E1)
├── gleam.toml (E2) ──declares──▶ deps {gleam_stdlib, gleam_erlang, gleeunit}, NOT gleam_otp
├── manifest.toml (E3) ──locks──▶ exact versions of those deps  (committed)
├── .gitignore (E7) ──excludes──▶ build/ , *.beam , *.ez , erl_crash.dump
├── smoke.sh (E6) ──runs──▶ build + test (gates E4 + E5 green)
├── README.md (E8) ──points to──▶ dossier §6 (single source of truth)
├── src/glp/<subsystem>.gleam ×8 (E4) ──1:1──▶ glp_runtime/lib/<subsystem>/  (Dart SoT)
└── test/glp_gleam_test.gleam (E5) ──exercises──▶ build-and-run path
```

External (unchanged) relationships:
- `codeconv` `dart_gleam` langpair (F2) ──recognizes via config──▶ `glp_gleam` (FR-008; R-004) —
  **no stage-tool source change**.

## State / lifecycle

The subtree has no runtime state. Its only lifecycle transition is **absent → created (green
baseline)**; downstream features (F4+) transition individual placeholders from *empty* to *ported*.
F3 owns only the absent→baseline transition.
