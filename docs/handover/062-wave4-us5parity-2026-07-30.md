## US3 recon (file:line-cited map)

- **T015 factor-out-compiler — essentially already done (C#/.NET line).** `GlpCompiler.Compile(source)
  → BytecodeProgram` (`out/csharp/lib/compiler/compiler.cs:49`) produces the compiled artifact without
  executing. `GlpEngine.LoadSource` compiles+stores without running (`out/csharp/lib/engine/glp_engine.cs:299`).
  `BytecodeRunner` executes separately (`out/csharp/lib/bytecode/runner.cs:446`). Seam is real → T015 = verify/document.
- **T016 wire envelope — partial.** `csharp/glp_il_codec` `IlCodec.Encode/Decode` (`IlCodec.cs:20/54`)
  serializes `BytecodeProgram` ↔ bytes with a 2-byte `PayloadHeader` (Version=0x01). MISSING (add
  additively): real **`il_version`**, **`integrity_digest`** (no checksum/hash anywhere today),
  **`source_metadata`** (module/program id). `compiled_form` = existing IlCodec bytes.
- **T019 multi-accept — seam is single-accept.** `TcpTransport.ListenAsync` accepts one client then
  `Stop()`s (`csharp/glp_link/transports/TcpTransport.cs:40-49`), comment defers multi-accept to
  "Phase 6" (= this wave). Multi-accept exists only in `QuicTransport.QuicListenerHandle.AcceptAsync`
  (`QuicTransport.cs:128-145`).
- **T020 ZMQ — from scratch.** No NetMQ/ZeroMQ dependency anywhere in `csharp/` (checked all .csproj).
  Introducing it adds a new external dependency — **flag to operator before adding**.
- `glp_wire_registry` = canonical payload discriminant table (0x10 il_program / 0x11 result_envelope /
  0x12 crdt_message).
