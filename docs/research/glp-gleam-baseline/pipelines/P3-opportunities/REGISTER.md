## Scope envelope (governs every row — honesty, load-bearing)

- **AtomVM-proven primitives** (F1 `hello-glp-term`): raw `erlang:spawn` + `gleam_erlang` Subjects + selective `receive` (+ `receive … after`), `self()`, `make_ref()`. (`README.md:13-23`; DOSSIER §3.1.)
- **Plain-BEAM-confirmed but AtomVM-UNVERIFIED** (need a spike, flagged ⚠ per row): `monitor`/`link`/`trap_exit`/`spawn_link` (O-09, O-18), `send_after`/`start_timer` (O-19), long-lived acceptor-loop process (O-70), `gen_tcp` `Timeout`-arg semantics (O-15), `/float` bit-syntax extraction (O-48), fault-as-mailbox refold (O-16).
- **Flagged OUT (not opportunities):** OTP `proc_lib`/`gen_*`/supervisors, disterl/epmd, hot-code-loading on AtomVM, ETS-as-heap, atoms-as-names. (CONC-T3, DOSSIER §3.1/§3.5, FORK-A2/B2.)
- **Hard line:** the M1 engine is the owner/spike-ratified **single scheduler-actor with ZERO spawns** (DOSSIER §1.1; `heap.gleam:69-71`) — BEAM *concurrency* gives M1-engine-internals essentially nothing; concurrency/platform wins land on **M2, the maGLP runtime (F8), the link layer (F9), and the BEAM-host REPL/front-end**. Immutability/ADT/pattern-match wins land on **both** the M1 device engine (F4/F5) and the BEAM-host front-end (DOSSIER §3.5).
- **Two seams kept distinct:** M1 **ED-6 bytecode-on-wire codec** (little-endian; unbuilt `csharp/glp_il_codec` port) and the **M2 term-level codec** (big-endian; Dart `payload_serializer.dart`). Bit-syntax simplifies each but does NOT merge them (ED-1).

## Traps & counterweights (recorded — NOT opportunities; the contract is faithfulness-judged)

These tempting-but-unfaithful uses are surfaced so the roadmap does not bank them:

- **TRAP-1 (CONC-T1) — "variable-as-process so `receive` handles suspension":** REJECTED on faithfulness — a process-cell heap injects message-ordering nondeterminism (FB-M1-35 → distributed-disarm race); BEAM `receive` resumes where it blocked, but GLP mandates resume-at-κ / wake-and-retry-all-clauses (FB-M1-38); + per-cell `spawn` vs the ~512K floor. M1 = ONE actor, zero spawns. (DOSSIER §2.4/FORK-A2/§1.1.)
- **TRAP-2 (CONC-T2 / C-2) — immutable value-copy makes single-fire HARDER:** the shared `SuspensionRecord` disarm-once mechanism vanishes; no concurrency primitive fixes it — F5 MUST add `(goal_id, suspension_generation)` dedup (bare `goal_id` breaks FB-M1-38). An added obligation, not a saving (pairs with O-24). (DOSSIER §1.3,§5.)
- **TRAP-3 (CONC-T3) — disterl / OTP supervisors are NOT a usable substrate on AtomVM:** M2 cross-instance must ride the ED-1 term seam over raw `spawn`+Subjects; supervision hand-rolled. (DOSSIER §3.5/§3.1; DECISIONS ED-1.)
- **TRAP-4 (critic) — first-class-funs / closure-threaded bytecode engine:** REJECTED — obscures the PC-addressed HEAD/GUARD/BODY transitions the parity bar pins (FB-M1-07 `RUN:2309-2447`); perf, not simplification.
- **TRAP-5 (critic) — proper-tail-calls deleting the tail budget:** NOT a win — `tailBudget` is inter-goal fairness within the single actor (BEAM preemption is between *processes*, no M1 help), and GLP's nested unify/deref recursion is not tail-positioned.
- **CW-1 (C-1) — `MutualRefTerm` mutable `_currentWriterAddr`:** the one place immutability likely COSTS (threaded tail-writer addr vs in-place bump); excluded from the F4 core (R-002/R-008) — an F5/F9 re-expression, not a deletion.
- **CW-2 (C-3) — pinned obligations untouched by this angle:** FB-M1-40 `forward_to_terminal` Dart-line still unpinned (RISK-CITE-1); 64-bit `ConstInt` overflow parity is masked on plain BEAM (Gleam `Int` = bignum) and MUST be exercised on AtomVM (no bignum). (DOSSIER §5; `PARITY-BAR.md:94,150`.)
